لینگوفارسی - پروژه اندروید

این پوشه یک پروژه Android Studio است که نسخه وب لینگوفارسی را در یک پوسته اندرویدی مستقل اجرا می‌کند.
فایل APK از پیش ساخته‌شده نیست؛ برای ساخت APK باید پروژه را در Android Studio باز و Build کنید.

روش ساخت APK:
1) Android Studio را روی رایانه نصب کنید.
2) از File > Open پوشه Lingofarsi-Android را انتخاب کنید.
3) صبر کنید Gradle Sync تمام شود.
4) از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را انتخاب کنید.
5) پس از پایان، روی اعلان locate کلیک کنید تا فایل app-debug.apk را پیدا کنید.
6) فایل APK را به گوشی اندرویدی منتقل و نصب کنید. ممکن است لازم باشد اجازه نصب از این منبع را در تنظیمات اندروید فعال کنید.

نیازمندی‌ها:
- Android Studio و Android SDK 35
- اتصال اینترنت فقط برای دریافت ابزارهای Gradle/SDK در اولین ساخت

شناسه برنامه: ir.lingofarsi.app
حداقل اندروید: Android 6.0 (API 23)

نکته:
این نسخه پوسته اندرویدی اولیه است. ذخیره‌سازی درس‌ها در مرورگر داخلی دستگاه انجام می‌شود. حساب کاربری آنلاین، همگام‌سازی ابری، پرداخت، اعلان و تشخیص گفتار هنوز پیاده‌سازی نشده‌اند.


ساخت APK بدون Android Studio با GitHub Actions:
۱) کل پوشه Lingofarsi-Android را در یک مخزن GitHub بارگذاری کن.
۲) در GitHub وارد زبانه Actions شو.
۳) اگر پیامی برای فعال‌سازی Actions دیدی، آن را فعال کن.
۴) گردش‌کار Build Lingofarsi APK را انتخاب و روی Run workflow بزن.
۵) پس از پایان موفق، در صفحه اجرای workflow به بخش Artifacts برو و فایل lingofarsi-debug-apk را دانلود کن.
۶) فایل ZIP دانلودشده را باز کن؛ فایل app-debug.apk داخل آن است.

نکته: این گردش‌کار APK آزمایشی (debug) می‌سازد، نه نسخه امضاشده برای انتشار در فروشگاه.
